# Ledger · 链上账本

一套关于区块链原理、数字资产资金流动与交易平台工程实现的系统性教程网站。

## 内容结构

| 章节 | 主题 | 核心内容 |
|---|---|---|
| I | 区块链原理 | 哈希函数、非对称加密、数字签名、默克尔树、UTXO 与账户模型 |
| II | 形成与共识演进 | 拜占庭将军问题、PoW、PoS、DPoS、分叉与最终性、攻击经济性 |
| III | 资金流路径 | 六层资金链路、入金通道、稳定币闸门、市值算法、利益分配 |
| IV | 交易与撮合 | 订单簿、撮合优先级、订单类型、延迟优化、清算结算、AMM |
| V | 期权与杠杆 | 永续合约、资金费率、逐仓全仓、强平引擎、期权希腊字母、隐含波动率 |
| VI | 平台开发全貌 | 系统架构、账务系统、撮合内核、行情推送、风控清算、钱包安全、技术栈、合规 |
| 附 | 术语表 | 70+ 条核心术语，支持搜索与分类筛选 |

## 交互演示

1. **哈希链仿真器**（第一章）— 修改区块交易内容，观察链如何断裂
2. **订单簿撮合引擎**（第四章）— 推送市价买单，观察逐层吃单与滑点
3. **K 线图生成器**（第四章）— 切换牛熊震荡形态，Canvas 手绘渲染
4. **资金流模拟器**（第三章）— 拖动滑块，看资金在六层链路中的损耗
5. **杠杆爆仓计算器**（第五章）— 实时计算强平价、保证金收益率与清算距离

## 技术实现

- 纯静态站点，零依赖、零构建
- 原生 HTML / CSS / JavaScript，无任何框架
- 图表使用 Canvas 2D 手绘，无第三方图表库
- 响应式布局，适配桌面与移动端
- 深色主题设计系统：墨蓝底色 + 香槟金点缀 + 衬线标题

## 本地运行

直接双击 `index.html` 即可打开。或启动本地服务：

```bash
python -m http.server 8000
```
